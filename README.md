# Nitheshwaran S — GitHub Pages Portfolio

This is the **single-file fixed version**. The profile photo and resume are embedded directly inside `index.html`, so the View Resume button does not depend on an `assets` folder.

## GitHub upload — important
1. Open your GitHub account: `Nitheshwaran-GLOBAL`.
2. Create/open the repository, for example `nitheshwaran-portfolio`.
3. Upload **`index.html` directly into the repository root**. Do **not** upload the ZIP file itself into the repository.
4. Commit to the `main` branch.
5. Go to **Settings → Pages → Deploy from a branch → main → /(root)**.
6. Open the GitHub Pages URL shown there.

Expected URL:
`https://Nitheshwaran-GLOBAL.github.io/nitheshwaran-portfolio/`
